## Agent 工作流：音视频转录整理

### 触发条件

用户发送一个播客/视频/音频链接，或上传一个本地音频文件。

### 步骤

1. MUST 确认收到链接或文件。如果格式不明确，MUST 反问"请发送播客/视频链接，或告诉我本地文件路径"。
2. MUST 判断来源类型：小宇宙、B站、YouTube、本地文件、其他。飞书妙记 MUST 拒绝。
3. SHOULD 优先查找是否有现成字幕（如 YouTube 字幕）。有字幕则直接使用，跳过 ASR。
4. 没有现成字幕时，MUST 使用 yt-dlp 下载音频（或直接读取本地文件）。
5. MUST 检查音频格式和时长。超过 2 小时的音频 SHOULD 分段处理。
6. MUST 使用 faster-whisper 进行语音识别转录。
7. MUST 清洗转录稿：去时间戳、去说话人标签、去口水话和重复句、修正常见 ASR 错词（尤其人名、公司名、术语）。
8. MUST 按话题分段，加简短标题。标题 MUST 来自真实内容，MAY NOT 使用"其他有效观点""补充说明"等模糊标题。
9. SHOULD 对重要判断、金句、关键数据适度加粗。
10. MUST 把整理稿写入飞书文档，标题为"[来源平台]-[原标题]-整理稿-YYYY-MM-DD"。
11. MUST 验证飞书文档目录结构和权限，确认用户能打开。
12. MUST 把飞书文档链接交付给用户。

### 成功标准

- 无时间戳、无说话人标签
- 无"其他有效观点"等垃圾桶标题
- 不是摘要式要点，是分享式提纯稿
- 保留了关键案例、数字、判断链和重要原话
- 主要 ASR 错词已修正
- 飞书文档目录正常、用户有访问权限

### 失败处理

- 链接无法下载 → 按登录墙 / 地区限制 / 平台不允许 / 没有音频分开说明，建议用户换公开链接或提供本地文件
- 音频超长（>2小时） → 自动分段处理，每段独立转录后合并
- ASR 转录质量极差（大量乱码） → 标注"转录质量异常，建议人工校对"，仍交付初稿
- 飞书权限授予失败 → 交付文档链接，附注"文档已创建但协作者权限未完成，请手动添加"

### 人工兜底

- 无法下载的非公开内容 MUST 说明原因并结束，MUST NOT 绕过登录墙
- ASR 无法确认的专有名词标注[待确认]，由用户最终校对
- 小红书 / 抖音 / 公众号 / 视频号 / 飞书妙记 MUST 拒绝
