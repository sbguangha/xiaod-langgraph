# 音视频转录整理助手（小D）

## 它是什么

这是一个音视频转录整理 Agent，把播客/视频/会议录音链接变成干净可读的飞书文档。

## 省了什么人工

- 之前：手动下载音频→找转录工具→等转录→手动修错字→分段加标题→粘贴飞书→调格式→分享，每期播客大约2小时
- 现在：发一个链接给小D，等10分钟，拿到飞书文档链接
- 量化：原来 2 小时 → 现在 10 分钟

## 用了什么工具

- LangGraph（编排岗位流程、状态和验收）
- Vue + FastAPI（本机控制台：提交任务、看进度、打开结果）
- yt-dlp + ffmpeg（下载音视频）
- faster-whisper（语音转文字）
- 飞书开放平台 + WebSocket Bot（创建文档、管理权限、私聊交付）
- LangSmith（按节点打点，可选）

官方航海默认栈是 Hermes + Codex + 飞书 CLI。本仓库按同一岗位、流程和 7 条验收实现，不安装 Hermes。

## 输入

- 输入 1：公开播客链接（小宇宙分享URL）
- 输入 2：公开视频链接（YouTube/B站URL）
- 输入 3：飞书妙记/会议录音（会议ID或妙记链接）
- 输入 4：本地音频文件路径（.mp3/.m4a/.wav）

## 如何触发

1. 网页：先 `uv run xiaod web`，再 `cd web && npm run dev`，在控制台粘贴链接。
2. 飞书：配置应用后 `uv run xiaod bot`，私聊 Bot 发送链接。
3. 命令行：`uv run xiaod run "请转录 <链接>"`

## 输出示例

一份飞书文档，包含：按主题分段的整理稿、具体标题、加粗重点、无时间戳无口水话。

## 别人怎么用

1. 复制 `.env.example` 为 `.env`，填写飞书和大模型密钥。
2. `uv sync --extra dev` 安装 yt-dlp 和 faster-whisper；本机安装 ffmpeg，或把路径写入 `FFMPEG_BIN`。用 `uv run xiaod doctor` 确认三件套都在。
3. 用上面三种入口之一发送公开链接。
4. 打开返回的飞书文档，确认目录和权限。

## 注意事项

- 不能处理需要登录的付费内容
- ASR 转录人名/术语可能有错字，重要内容建议人工校对
- 超过2小时的长音频可能需要分段
- 不要把 App Secret 写入文档或聊天
- 飞书权限授予失败时需手动处理
- 本期不做小红书 / 抖音 / 公众号 / 视频号采集
